# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.21.x  | :white_check_mark: |
| < 0.21  | :x:                |

0.21.0 is the first RiaGraph release. Earlier version numbers belong to the projects this
one was forked from and are not supported here.

## Reporting a Vulnerability

Report security issues through
[GitHub private vulnerability reporting](https://github.com/cntSafety/RiaGraph/security/advisories/new)
on this repository. Please do not open a public issue.

Include a description of the issue, the steps you took to reproduce it, the affected
versions and, if known, mitigations. We aim to respond within 7 working days. If the
issue is confirmed we will open a Security Advisory. This project follows a 90 day
disclosure timeline.
