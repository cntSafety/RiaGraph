# Contributing

Welcome! We are excited that you are interested in contributing to RiaGraph.
Before submitting your contribution though, please make sure to take a moment and read through the following guidelines.

RiaGraph is a fork of [ladybug](https://github.com/ladybugdb/ladybug), which is itself a fork of [Kùzu](https://github.com/kuzudb/kuzu). <!-- riag-rename:skip lineage, plan section 1 -->
Where ladybug's emphasis is feature breadth, **RiaGraph's emphasis is quality and reliability**. <!-- riag-rename:skip lineage, plan section 1 -->
Changes that make the system more predictable, better tested or easier to reason about are welcome even when they add no features.

If you have a question or need help, open an [issue](https://github.com/cntSafety/RiaGraph/issues) or start a [discussion](https://github.com/cntSafety/RiaGraph/discussions).

## General Steps and Guidelines to Contribute
* Discuss your intended changes on GitHub first, so we can assign appropriate issue(s) for you to work on.
* Do not commit/push directly to the main branch. Instead, create a fork and open a pull request.
* While you're working on the issue, please merge frequently with the main branch.
* All pull requests with new features and bug fixes should be covered by proper tests.
* Avoid large pull requests - they are much less likely to be merged as they are incredibly hard to review.
* We reserve full and final discretion over whether or not we will merge a pull request. Adhering to these guidelines is not a complete guarantee that your pull request will be merged.

Thank you for your contribution to RiaGraph! We're grateful for your time and effort, and we look forward to working with you.
